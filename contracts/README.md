# Contracts

**Prefer a generated artifact over a file in here.**

`creater-ai-backend` publishes `src/modules/billing/api.schema.json`, generated by
`npm run api:schema` from the same zod schemas its routes validate with.
`creater-ai-frontend` turns that into `src/types/billing.ts` via `npm run types:billing`.
That is a real contract: it is derived from what the server enforces, and a stale copy
shows up in review.

A markdown file in this folder cannot do that — it is prose that drifts. So:

- If the contract can be generated, generate it. Put a pointer here, not a copy.
- Only write a file here for something with no machine-readable form, and say plainly
  that it is a description rather than a source of truth.
- Each file carries frontmatter `owner: <repo>`. Only the owner edits it, and only under
  an approved ticket. Everyone else reads it.
